# Цифровой деканат · МГИМО

Работающий прототип кабинета студента для кейса «Цифровой деканат будущего».
Задача — не «ещё один портал», а один экран, который отвечает на вопрос
«что сейчас?», и система, где статус заявки виден как трекинг доставки.

**Демо:** два тестовых аккаунта, пароли не нужны. Все студенты и оценки вымышлены.

| Аккаунт       | Кто это                      |
| ------------- | ---------------------------- |
| Анна Ковалёва | 2 курс, МЭО, группа МЭО-2-14 |
| Тимур Ахметов | 3 курс, МО, группа МО-3-08   |

## Быстрый старт

```bash
make install      # yarn 4, node-modules
make dev          # http://localhost:5173
make check        # lint + format + types + tests
make build        # прод-сборка в dist/
```

Нужен Node ≥ 22.12 (в `.nvmrc` — 22 LTS) и yarn 4.

## Что реализовано

| Экран            | Что внутри                                                                   | MoSCoW      |
| ---------------- | ---------------------------------------------------------------------------- | ----------- |
| `/login`         | 2 тестовых аккаунта, заглушка «Вход через Госуслуги»                         | Must        |
| `/`              | лента «Сегодня», следующая пара с обратным отсчётом, дедлайны, заявки        | Must/Should |
| `/schedule`      | Сегодня / Завтра / Неделя, изменения инлайн (старое время + причина)         | Must        |
| `/grades`        | средний балл, прогресс по дисциплинам, карта компетенций с рыночным сигналом | Must/Could  |
| `/requests`      | трекер заявки, ответственный, срок, бейдж верификации, форма в 3 шага        | Must/Should |
| `/notifications` | критично / важно / инфо, управление каналами                                 | Must        |
| `/profile`       | данные студента, «Кто что видит», настройки демо, выход                      | Should      |

Дополнительно: тёмная тема, режим демо-сбоев (случайные ошибки сети), скелетоны,
пустые состояния с маскотом, конфетти на успешных действиях, экран 404.

**За пределами прототипа** (по ТЗ — только описание концепции): ИИ-ассистент,
RAG, кабинет работодателя, государственная аналитика, блокчейн, VR. В интерфейсе
этих экранов нет осознанно: прототип не должен обещать больше, чем показывает.

## Почему этот стек

**React 19 + Vite + Tailwind v4 + shadcn-подход.** В `~/Repositories` уже есть два
работающих примера этой связки (`syneps`, `lawcopilot`) и инженерный каркас
`finance_academy` (Makefile, husky, gitleaks, Vitest).

| Альтернатива | Почему не взяли                                                      |
| ------------ | -------------------------------------------------------------------- |
| Next.js 16   | SSR/RSC нечем оправдать: данных с сервера нет, деплой — статика      |
| Kontur UI    | зрелый, но «энтерпрайз»: перекрасить в тёплый фирменный стиль дорого |
| antd         | быстрые таблицы, но чужой визуальный язык и CSS-in-JS                |
| Mantine      | приятно из коробки, но два источника стилей вместе с Tailwind        |
| Vue/Nuxt     | экосистема «красивых» компонентов беднее, команда-донор на React     |

Компоненты shadcn-подхода живут в репозитории, а не в зависимости: полный контроль
над внешним видом, Radix-паттерны доступности, нулевая привязка к чужой теме.

## Дизайн-система

Палитра посчитана по WCAG AA (ГОСТ Р 52872-2019) и проверена скриптом:

| Токен                  | Светлая   | Контраст                     | Тёмная    |
| ---------------------- | --------- | ---------------------------- | --------- |
| `--brand` (МГИМО)      | `#0B2E59` | 13.6:1 на белом              | `#9ECBFF` |
| `--primary` (действие) | `#0D5BD7` | 6.0:1 · 5.3:1 на мягком фоне | `#6BA6FF` |
| `--foreground`         | `#1B2733` | 15.2:1                       | `#E6EDF5` |
| `--muted-foreground`   | `#5A6B7C` | 5.5:1                        | `#9FB0C3` |
| `--success`            | `#0F6B4E` | 5.9:1 на мягком фоне         | `#4ADE9F` |
| `--warning`            | `#B54708` | 5.1:1                        | `#F5B556` |
| `--danger`             | `#B42318` | 5.8:1                        | `#FF8B80` |

- **Шрифт:** Golos Text, variable, self-hosted (`public/fonts`, 78 КБ) — демо
  работает без интернета и без Google Fonts.
- **Форма:** радиусы 12/20/24 px, двухслойные мягкие тени, никакого тяжёлого
  glassmorphism (FPS на мобилке).
- **Няшность — в состояниях, не в данных:** маскот-совёнок в пустых состояниях,
  ошибках и успехе; spring-нажатия; скелетоны; конфетти. Расписание и оценки
  остаются спокойными и читаемыми.
- **Motion:** 180–240 мс, всё под `prefers-reduced-motion`.

## Тесты и качество

```bash
make test            # Vitest (40 тестов)
make test-coverage   # покрытие
make lint            # ESLint 9 + jsx-a11y
make format-check    # Prettier
make type-check      # tsc --noEmit
make ci-critical     # то, что гоняет pre-push
```

Покрытие: 53 % строк в целом, `app/store` — 80 %, `shared/ui` — 73 %,
`pages` — 28 % (экраны покрыты рендер-тестами главного сценария). Критичная
логика — даты, статусы заявок, каналы уведомлений — покрыта полностью.

Проверено вручную в Chromium (Playwright):

- **axe-core (WCAG 2.1 AA): 0 нарушений** на всех экранах, включая тёмную тему;
- **320 px:** горизонтальный скролл = 0 px;
- тач-таргеты нижней навигации — 61 px (≥ 44 px по ГОСТ);
- ошибок в консоли нет.

## Данные и границы

Мок-слой — `src/shared/api/mock.ts`. Он честно имитирует сеть: задержка 260–520 мс,
а в «режиме демо-сбоев» (профиль → настройки) — 40 % ошибок, чтобы показать
состояния `error` и `retry`.

Ключевые принципы, заложенные в интерфейс:

1. **Верификация ≠ контроль.** Экран «Кто что видит» показывает матрицу ролей и
   переключатель «что уходит в государственный контур» (только агрегаты).
2. **Источник данных виден.** У карты компетенций указано: «словарь формулировок +
   ручная верификация, обновлено 12.10.2026». Если связки нет — пишем «данных нет»,
   а не показываем «магическую рекомендацию».
3. **Разделение доступа.** Селекторы фильтруют заявки и уведомления по `studentId`
   из сессии: чужие данные не рендерятся даже при подстановке URL.

## Деплой

`make build` → `dist/` — обычная статика. Для GitHub Pages:

```bash
BASE_URL=/digitalMgimo/ make build
```

`public/404.html` — SPA-fallback для статических хостингов (BrowserRouter).

## Ограничения прототипа

- Настоящей авторизации нет: тестовые аккаунты — часть демо.
- Бэкенд не подключён: замените `mock.ts` на HTTP-клиент, сохранив сигнатуры хуков.
- Скриншот-тесты 320/360 и axe не в CI (запускались вручную); для регрессий —
  добавить Playwright + `@axe-core/playwright` в pipeline.
- Главный бандл ≈ 183 КБ gzip. При росте — ленивая загрузка маршрутов.
