# AGENTS.md — карта проекта «Цифровой деканат»

> **Что это:** работающий прототип кабинета студента для кейса «Цифровой деканат
> будущего» (МГИМО). Не личный кабинет вуза, а демонстрация продуктовых решений:
> единая лента «Сегодня», трекинг заявок, карта компетенций, приоритизация
> уведомлений, экран «Кто что видит».
>
> **Ключевое ограничение:** данные вымышленные, реальных интеграций нет.
> Госуслуги, ФИС ГИА, 1С и API вуза — заглушки, показывающие точку интеграции.
> Нельзя выдавать демо-данные за реальные: это прямо противоречит требованию
> «не обещать больше, чем система может показать честно».

---

## 1. Стек

| Слой      | Решение                                                     |
| --------- | ----------------------------------------------------------- |
| UI        | React 19 + TypeScript (strict)                              |
| Сборка    | Vite 7 (SPA, без SSR)                                       |
| Стили     | Tailwind CSS v4 + дизайн-токены в `src/styles/globals.css`  |
| Анимации  | `motion` (бывший framer-motion), `canvas-confetti`          |
| Данные    | `@tanstack/react-query` + мок-слой `src/shared/api/mock.ts` |
| Состояние | `zustand` (+ persist) для сессии, заявок и уведомлений      |
| Роутинг   | `react-router-dom` (BrowserRouter)                          |
| Иконки    | `lucide-react`                                              |
| Шрифт     | Golos Text, self-hosted в `public/fonts`                    |
| Тесты     | Vitest + Testing Library + jest-dom                         |
| Качество  | ESLint 9 (flat) + Prettier + husky + gitleaks               |

Почему так, а не Next/Vue — см. `README.md` § «Почему этот стек».

## 2. Структура

```text
src/
├── app/                 # провайдеры, маршруты, store сессии
│   ├── app.tsx          # QueryClient + BrowserRouter + RequireAuth
│   └── store/           # zustand: сессия, тема, заявки, уведомления
├── pages/               # экраны: today, schedule, grades, requests, notifications, profile, login, 404
├── widgets/             # app-shell, bottom-nav, access-map
├── entities/            # lesson-card, request-status, competency-card, priority-badge
├── shared/
│   ├── api/             # типы, мок-данные, query-хуки
│   ├── lib/             # cn, dates, confetti, use-now
│   └── ui/              # дизайн-система: button, card, badge, sheet, toast, mascot…
└── styles/globals.css   # токены, шрифт, утилиты теней, reduced-motion
```

**Направление зависимостей:** `pages → widgets → entities → shared`.
Обратные импорты запрещены: `shared` не знает про `pages`.

## 5. Маршруты и роли

| Маршрут          | Экран                                        | MoSCoW      |
| ---------------- | -------------------------------------------- | ----------- |
| `/login`         | вход, 2 тестовых аккаунта, заглушка Госуслуг | Must        |
| `/`              | лента «Сегодня» + следующая пара             | Must/Should |
| `/schedule`      | сегодня / завтра / неделя, инлайн-изменения  | Must        |
| `/grades`        | дисциплины + карта компетенций               | Must/Could  |
| `/requests`      | заявки, трекер, форма в 3 шага               | Must/Should |
| `/notifications` | 3 приоритета + каналы                        | Must        |
| `/profile`       | профиль, «Кто что видит», настройки демо     | Should      |

Доступ: `RequireAuth` в `src/app/app.tsx`. Сессия хранится в zustand+localStorage.
Чужие заявки недоступны: селекторы фильтруют по `studentId` из сессии.

## 6. Готчи

1. **Внутренняя документация — вне git.** `requirements.md`, `docs/requirements/`
   и `ai/tasks/` в `.gitignore`: публикуется только код. Не добавлять их в индекс
   и не ссылаться на них из `README.md`/`AGENTS.md`. Проверка — `make docs-check`.
2. **Демо-сбои** включаются в профиле. Они нужны для показа состояний ошибки;
   по умолчанию выключены. Флаг — `localStorage['dekanat.chaos']`.
3. **Node 25 не LTS.** В `.nvmrc` зафиксирован Node 22. Нечётные версии Node
   поддерживаются Vite, но для воспроизводимости используйте 22.
4. **Контраст.** Любой новый цвет проверять на 4.5:1 для текста и 3:1 для
   границ/крупного текста. Статусы — всегда текст + иконка, не только цвет.
5. **Тач-таргеты ≥ 44 px.** В `Button` это `min-h-11`; не уменьшать.
6. **`prefers-reduced-motion`.** Все анимации обязаны уважать настройку
   (см. `globals.css` и `useReducedMotion` в компонентах).
7. **Мок-даты.** Прошлые события считаются через `ago()`, будущие — через `at()`.
   Не использовать фиксированные часы: лента «Сегодня» должна быть живой в любой момент.
8. **Коммиты** — Conventional Commits (хук `commit-msg`), `--no-verify` не использовать.
9. **Селекторы zustand.** Селектор, который возвращает новый массив/объект, обязан
   использоваться через `useShallow` из `zustand/react/shallow`. Иначе React 19
   уходит в бесконечный ререндер и экран становится пустым (проверено на практике).
10. **Сетки с длинным текстом.** У грид-элементов с карточками обязателен `min-w-0`,
    иначе на 320 px появляется горизонтальный скролл (проверка — Playwright).
